# clients — 前端（原生 HTML / Canvas，零构建、与服务同源）

全部页面为原生 HTML + Canvas + 原生 JS 实现，页面业务逻辑内联，通用样式与键盘交互集中在 `shared/`，**无构建流水线**；所有网络地址为相对路径，任何域名或隧道下均可直接运行。由 `server/app.py` 挂载到 `/app`（含根路径兜底），页面与静态资源均设 `no-store`（改完刷新即生效，不会加载到旧版）。

## 页面一览

| 页面 | 路径 | 用途 |
| --- | --- | --- |
| `index.html` | `/app/index.html` | 入口导航页：学习流程说明 + 学科选择 / 登录注册 / 用户中心 / 学情分析 / 监控台入口。 |
| `subject_select/` | `/app/subject_select/`（根路径 `/` 也指向它） | 学科选择页：11 个学科卡片，同科多老师时弹风格浮层，选定后跳转 1v1 辅导页。 |
| `student_tablet/` | `/app/student_tablet/` | **1v1 辅导主前端**：数字人 + 白板 + 麦控 + 课件 + 出题判题（见该目录 README）。 |
| `login/` | `/app/login/` | 登录 / 注册页（JWT 凭据存入 `localStorage["edu_auth"]`）。 |
| `user_center/` | `/app/user_center/` | 用户中心：查看账号信息、切换小学 / 初中学段（写入 `users.stage`，下次进课堂生效）。 |

## 全站 UI 规范

- 全站采用浅色教育配色：暖白背景 `#f7f8fa`、白色面板、深蓝灰正文 `#243248`、辅助文字 `#52647d` 与蓝色主操作 `#2563eb`；成功 / 提醒 / 错误采用深绿 / 棕橙 / 深红，搭配浅色状态底。课堂媒体区域保留深色底，不改变白板与课件内容颜色。
- 输入控件、焦点轮廓与触控目标保持统一；页面分别适配手机、平板和桌面布局。
- `shared/ui.css` 提供基础设计变量、可见键盘焦点及减少动画偏好；在页面内联样式后引入。
- `shared/ui.js` 提供跳转主内容入口，以及可见 `role="dialog"` / `aria-modal="true"` 弹窗的焦点约束与恢复；允许关闭的弹窗用 `data-dialog-close` 标记关闭按钮。开课闸门不提供绕过入口。
- 排版统一使用系统字体、温和标题字重与正文行距。学科页强调选课而非宣传，40 分钟仅作为建议学习时长；课堂将提问、课件与低频工具分区，录制入口收进“更多”。顶栏保留返回、课程名 / 学科、连接与麦控 / AI / 教师状态，以及仅管理员可见的技能管理入口；设备开关与版本信息收进“课堂设置”，支持点击外部和 Esc 收起。
- 登录页将体验账号说明折叠，说明其依赖演示环境，不影响正常登录注册。
- 用户中心沿用登录页的暖白配色与卡片式信息层级：账号资料只读，学段用两张单选卡切换；保存后同步 `localStorage`，并明确提示「下次进入课堂生效」。
- 学情分析页把「课时完成 / 学习掌握 / 互动率」拆成三列，不用单一分数掩盖差异；「未验证」与「人在心不在」必须显式可见，详情用事件时间线解释分数来源。
- 监控台提供应用健康状态、工具数量与最近成功刷新时间；手动 / 自动刷新均标明失败模块，12 秒超时后允许重试；后台标签暂停轮询。桌面连接设置页保持独立资源，适用于 Electron 打包。
- 修改后运行 `node scripts/check_frontend_js.mjs`（传入变更页面，新增页面也要传入）、`node --check clients/shared/ui.js` 和 `python -m pytest tests/test_frontend_pages.py -q`。浏览器预览可使用本机静态服务器；业务接口、音视频与登录成功链路仍需实际后端联调。

## 设计要点

- **鉴权贯穿全站**：登录页写 `localStorage["edu_auth"] = {token, user}`；学科页 / 学生端 / 用户中心读同一 key。HTTP 走 `Authorization: Bearer`，WebSocket 因浏览器不能自定义 Header 而走 `?token=`（见 `student_tablet` 的 `WS_PATH`）。
- **用户中心是学段的唯一自助入口**：页面读 `/api/auth/me`，保存时 `PATCH /api/auth/me/stage`，成功后回写 `edu_auth.user.stage`；学科页据此过滤学科，下一次 WebSocket 建连从数据库读取新学段。当前正在上的课不切换，避免中途换老师风格。
- **学情看板只读事件，不参与教学决策**：`/api/learning/reports` 返回聚合报告，`/api/learning/report/{id}` 返回单节课详情；学生 / 家长只能看自己，教师 / 管理员可筛选学生。前端每 30 秒静默刷新，页面不可见时暂停。
- **白板三层模型**：背景图（课件页图 / 学生题目图）+ Canvas 标注层 + DOM 文字层，标注坐标全为 0~1 归一化。
- **数字人双缓冲**：讲解视频与待机画面用双缓冲交叉淡化切换；视频不可用时回退照片木偶 + 音频能量驱动口型。
- **零构建的代价与纪律**：JS 内联在页面里，改前端的自检是 `node scripts/check_frontend_js.mjs clients/<页面>/index.html`（语法解析 + HTML 注释配对检查）。
